# Известные ограничения

Один файл на весь проект — ограничения способа работы и верификации.
Не дефекты (дефекты — в DEFECTS.md). Пополняется по волнам
(TZ UI v5 §13, п.5). Запись U44 — лимит на 4 изображения на сессию
анализа — зафиксирована в Волне 1.

| Ограничение | Где действует | Волна | Статус |
|---|---|---|---|
| Анализ изображений: не более 4 изображений на сессию анализа (TZ UI v5 U44): предыдущая сессия аудита погибла именно на этом. Скриншоты планируются пакетами — отбор наиболее информативных кадров — либо разносятся по сессиям | Все волны со скриншотами (U41-прогоны, U43) | 1 | действует с Волны 1 |
| Браузерная верификация UI недоступна (нет harness Playwright/Chromium в инструментах сессии): утверждение «хэш виден в интерфейсе» (U02) проверено присутствием константы в бандле (`grep -c 0d05041 web/dist/assets/*.js` = 1) и сверкой `/api/meta` c `git rev-parse --short HEAD`, а не скриншотом | Верификация U02, Волна 0 | 0 | снимают прогоны U41 (Волна 1): скриншот маршрута #/settings в `.a/reports/ui/` |
| `npm ci` блокирует postinstall-скрипты (allowScripts): esbuild postinstall не прогоняется; платформа-бинарь приходит через опциональную зависимость — сборка работает, но при смене платформы/версии esbuild может потребовать ручного `npm install-scripts approve` | Сборка web, Волна 0 | 0 | открыто (наблюдать при обновлении зависимостей) |
| Фото объявлений (фото-лента U17, обложки U15) — материалы правообладателей (авторы объявлений/застройщики); показ только владельцу системы, третьим лицам не передаются (ТЗ v4 §4.4). У API нет аутентификации: слушать можно только на локальном адресе или в сети, которой владеет оператор; публикация раздачи или фото наружу невозможна | Раздача UI (объект + список), Волна 2 | 2 | действует с Волны 2 |
| Установленная сборка PostGIS 3.4.2 — урезанная (776 функций против полных ~1200): нет перегрузки `ST_MakeEnvelope(…, boolean)` (только `(float8×4, integer)`), нет смешанного оператора `&& (geometry, geography)`, нет `typeof()`. Код U30 написан под эту сборку: bbox — `ST_MakeEnvelope($1..$4::float8, 0)::geography` (явные касты: pgx шлёт параметры unknown; каст в geography: оператор `&&` только geography/geography). При замене/пересборке PostGIS — перепроверить 0036-миграцию и запросы `map_objects.go` | U30 (эндпоинт карты), migration 0036 | 3 | открыто (связано с конкретной сборкой) |
| `geo_confidence ≥ street` = 11.78% (905/7684), порог C32 70% не достигнут: bazos в карточке отдаёт город+PSČ, улица только из текста. Карта (Волны 4–5) построена честно: точки — только building/street; postcode/municipality — заливка зоны, не точка на доме (ТЗ v4 §0.5) | U31–U40, C32 | 4 | действует; 70% недостижимы без другого источника улиц |
| U43 проверка на физическом устройстве не выполнялась в этой сессии (нет телефона в harness) | U43 | 4 | открыто |
| Раздел «Торги» не строится: источников аукционов нет (TZ v4 §13, Р8) | TZ v4 §6.1 | 4 | открыто |
| Phone-agent (этап 9 ТЗ v2) не начат: нужен телефон | ТЗ v2 этап 9 | — | открыто |
