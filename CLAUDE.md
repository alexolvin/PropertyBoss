# PropertyBoss

Проект: Go 1.22+ / PostgreSQL 16 + PostGIS / React + Vite / Telegram / OpenClaw.
ТЗ: `.tasks/PropertyBoss_TZ_v2.md` (раздел 0 — регламент исполнителя, соблюдать всегда).

## Правила расположения файлов

1. **Все задания** (ТЗ, задачи, постановки работ) — только в каталоге `.tasks/`.
2. **Все handoff-документы** (передания контекста между сессиями/исполнителями) — только в каталоге `.handoff/`.

Не создавать задания и handoff-файлы в корне репозитория или в других каталогах.
