# Security Policy

## Supported versions

No numbered release is published yet. Fixes land on the `main` branch.

## Reporting a vulnerability

Open a GitHub Security Advisory (preferred) or use the contact listed in the repository owner profile.
Do not file public issues for undisclosed vulnerabilities.

Please include reproduction steps and affected versions.

Do not include secrets, access tokens, or private network addresses in the report. The HTTP API has no authentication: do not expose it on a public interface.
